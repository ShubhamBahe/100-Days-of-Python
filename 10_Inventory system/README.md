# 📦 Inventory Management System

## 📖 Description

A menu-driven Inventory Management System built using Python.

## ✨ Features

- Add Product
- View Products
- Search Product
- Update Product
- Delete Product
- Calculate Total Inventory Value

## 🛠️ Concepts Used

- Functions
- Dictionaries
- Nested Dictionaries
- Loops
- Conditional Statements
- CRUD Operations

## ▶️ How to Run

```bash
python Inventory.py
```

## 📸 Sample Menu

```
1. Add Product
2. View Product
3. Search Product
4. Update Product
5. Delete Product
6. Total Value of Inventory
7. Exit
```

## 📚 Learning Outcome

Practised CRUD operations using nested dictionaries and built a real-world inventory management application.
