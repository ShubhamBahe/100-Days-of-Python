# Day 8 - Quiz Game 🎯

## 📌 Project Description

A command-line Quiz Game built using Python. The game asks multiple-choice questions, validates user input, calculates the score, and displays the final performance.

## ✨ Features

- Easy Mode
- Difficult Mode (Game Over after 2 wrong answers)
- Multiple-choice questions
- Input validation
- Score calculation
- Percentage calculation
- Performance rating
- Final scorecard

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

```bash
python Quiz_Game.py
```
