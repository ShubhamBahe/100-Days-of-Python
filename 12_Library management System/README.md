# 📚 Library Management System

## 📖 Description

A menu-driven **Library Management System** built using Python. This project allows users to manage library books by adding, viewing, searching, borrowing, returning, deleting, and tracking the availability of books.

---

## ✨ Features

- ➕ Add New Book
- 📋 View All Books
- 🔍 Search Book by ID
- 📕 Borrow Book
- 📗 Return Book
- 🗑️ Delete Book
- 📊 View Total Books
- 📚 Count Available & Borrowed Books
- 🚪 Exit Program

---

## 🛠️ Concepts Used

- Python Functions
- Lists
- Dictionaries
- List of Dictionaries
- Boolean Values (`True` / `False`)
- Loops
- Conditional Statements
- CRUD Operations
- User Input Handling

---

## 📂 Data Structure

Each book is stored as a dictionary inside a list.

Example:

```python
books = [
    {
        "id": "B101",
        "title": "Python Basics",
        "author": "Guido",
        "available": True
    }
]
```
