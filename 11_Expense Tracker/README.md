# 💰 Expense Tracker

## 📖 Description

A simple menu-driven Expense Tracker built using Python. This application helps users manage their daily expenses by allowing them to add, view, search, update, delete, and analyse expense records.

## ✨ Features

- ➕ Add Expense
- 📋 View All Expenses
- 🔍 Search Expense by Title
- ✏️ Update Expense
- 🗑️ Delete Expense
- 💵 Calculate Total Expense
- 🏆 Find Highest Expense
- 🚪 Exit Program

## 🛠️ Concepts Used

- Python Functions
- Lists
- Dictionaries
- List of Dictionaries
- Loops
- Conditional Statements
- CRUD Operations
- User Input Handling

## 📂 Data Structure

Each expense is stored as a dictionary inside a list.

Example:

```python
expenses = [
    {
        "title": "Pizza",
        "amount": 150,
        "category": "Food"
    }
]
```

## ▶️ How to Run

```bash
python ExpenseTracker.py
```
