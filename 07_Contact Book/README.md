# 📞 Day 07 - Contact Book

## 📌 Description

A simple Contact Book application built using Python. This program allows users to manage contacts through a menu-driven interface.

## ✨ Features

- ➕ Add a New Contact
- 📋 View All Contacts
- 🔍 Search Contact by Name
- ✏️ Update Contact Number
- 🗑️ Delete Contact
- ✅ Prevent Duplicate Contacts
- 📱 Validate 10-Digit Phone Numbers
- 🔠 Case-Insensitive Name Search

## 🛠️ Technologies Used

- Python 3

## 📚 Concepts Practiced

- Functions
- Dictionaries
- Loops
- Conditional Statements
- User Input Validation
- CRUD Operations (Create, Read, Update, Delete)
- Sorting Dictionary Data

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/ShubhamBahe/100-Days-of-Python.git
```

2. Navigate to the project folder.

```bash
cd 07_Contact_Book
```

3. Run the program.

```bash
python ContactBook.py
```
