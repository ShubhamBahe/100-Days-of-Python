## 📚 Day 9 - Student Management System

### 📌 Project Overview

A menu-driven Student Management System built using Python. This project performs CRUD (Create, Read, Update, Delete) operations using nested dictionaries.

### ✨ Features

* ➕ Add Student
* 👀 View All Students
* 🔍 Search Student
* ✏️ Update Student Marks
* ❌ Delete Student
* 🏆 Show Topper
* ✅ Input Validation
* 🔄 Menu-Driven Interface

### 🧠 Concepts Practiced

* Functions
* Loops (`while`, `for`)
* Conditional Statements (`if`, `elif`, `else`)
* Nested Dictionaries
* Dictionary Methods (`items()`, `pop()`)
* Input Validation
* CRUD Operations
* Basic Problem Solving

### 📂 Technologies Used

* Python 3
